# Driving HUD - 科幻驾驶仪表盘设计文档

## 概述

一个面向手机横屏使用的驾驶 HUD 页面，部署到 GitHub Pages。核心场景：手机垂直于地面放置，开车时浏览器横屏查看。提供方位、海拔、位置、日出日落、行驶距离等关键信息，科幻终端风格，信息突出醒目。

## 界面布局

```
┌─────────────────────────────────────────────────────┐
│  W  315  NW    N    NE  45  E  ← 方位指示条（顶部通栏）│
├───────────────────────┬─────────────────────────────┤
│                       │                             │
│   海拔                │              已行驶          │
│   1247m               │              12.4km         │
│                       │                             │
│  ◎ 河北省张家口市...   │           14:23:07          │
│                       │                             │
│  ☼ 05:32  ☽ 19:48    │                             │
│                       │                             │
└───────────────────────┴─────────────────────────────┘
```

- 顶部：方位指示条，通栏，线性字母风格
- 左侧：海拔（超大粗黑体）+ 位置 + 日出日落
- 右侧：行驶距离（大字）+ 当前时间

## 视觉设计

### 配色

- 背景：纯黑 `#050510`
- 主文字：终端绿 `#00ff88`
- 次要信息：降低透明度（0.5-0.7）

### 字体

- 海拔数字：`Arial Black` / `Helvetica Neue` 粗体，约 60-80px
- 其他文字：等宽字体 `Courier New` / `monospace`
- 方位条：等宽，小字号，字间距拉开

### 图标

使用 SVG 线条图标，纯绿色 `#00ff88`，几何化细线条风格：
- 位置：圆点 + 十字定位图标
- 日出：半圆 + 向上射线
- 日落：半圆 + 向下射线

## 方位指示条

- 固定宽度通栏，当前方向始终居中
- 两侧文字根据实际朝向滚动（类似 PUBG）
- 当前指向的字母/度数高亮，两侧渐暗（透明度递减）
- 底部一条细线分隔
- 使用 DeviceOrientationEvent 实时更新

## 数据来源

| 功能 | 在线方案 | 离线方案 |
|------|---------|---------|
| 地址解析 | 高德地图逆地理编码 API | 仅显示经纬度坐标 |
| 日出日落 | SunCalc 库（纯前端计算） | 同左（本身就离线） |
| 罗盘方向 | DeviceOrientationEvent（硬件） | 同左 |
| 海拔高度 | Geolocation API altitude | 同左 |
| 行驶距离 | Geolocation API 持续定位计算 | 同左 |

### 网络策略

- 首次加载检测网络状态
- 有网络时调用高德 API 获取详细地址
- 无网络时地址行显示经纬度坐标
- 坐标变化超过 10km 时才重新请求 API（避免频繁调用）

## 行驶距离

- 使用 Geolocation watchPosition 持续追踪
- 用 `localStorage` 持久化累计距离和最后定位坐标
- 页面刷新后恢复之前的累计值继续累加
- 提供重置功能（双击距离区域）清零

## 数据刷新频率

- 罗盘：DeviceOrientationEvent 实时更新（约 60fps）
- 定位：Geolocation watchPosition，约每秒更新一次
- 地址：坐标变化超过阈值时才重新请求
- 时间：每秒更新

## 屏幕常亮

使用 `navigator.wakeLock` API 防止手机息屏。

## 状态与异常处理

| 场景 | 处理方式 |
|------|---------|
| 定位权限拒绝 | 中央显示"请开启定位权限"提示 |
| 陀螺仪权限拒绝 | 方位条显示"--"，不显示方向 |
| 无网络 | 地址行显示经纬度坐标，日出日落正常（本地计算） |
| GPS 信号弱 | 海拔显示"--"，保持上次有效距离 |
| 首次打开 | 弹出权限请求，引导用户授权 |

## 技术栈

- 纯 HTML + CSS + JS，无框架依赖
- 高德地图 Web 服务 API（逆地理编码，通过 fetch 调用）
- SunCalc 库（日出日落计算）
- 部署到 GitHub Pages（静态站点）
